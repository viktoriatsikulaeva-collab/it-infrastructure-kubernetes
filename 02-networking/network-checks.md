# Network Diagnostics Lab

## Objective
Verify network interfaces, DNS and HTTPS connectivity.

## Commands
- `ls /sys/class/net` - inspect interface names.
- `getent ahostsv4 example.com` - test DNS resolution.
- `curl` - test HTTPS connectivity.
