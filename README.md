
# IT Infrastructure & Kubernetes Administration Lab

## About This Project

This repository documents my hands-on learning journey in Linux system administration, networking, Docker, and Kubernetes.

My goal is to develop practical IT infrastructure and operations skills and build a technical portfolio for IT-driftsfaget apprenticeship opportunities in Norway.
